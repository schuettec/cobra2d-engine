 When modeling in blender for use in LibGDX use the screenshots to avoid misconfiguration.

 Material - important note!
 --------------------------

 Change the emission color to Black. LibGDX or fbx-conv or g3dj-exporter in Blender set the wrong emission texture. Something in the chain misintepret the emission.

 See screenshot: blender-material-libgdx-emission-fix.png

 If this does not work change the emission attribute while model loading:
      for (Material material : modelInstance.materials) {
        material.remove(ColorAttribute.Emissive);
      }
